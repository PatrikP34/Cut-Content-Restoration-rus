Как запустить сборку
Убедитесь, что в папке рядом с build_russian_patch.bat есть:

russian_patch00m.bin — исходный русский архив;
original_patch00m.bin — чистый английский архив до Restoration;
restored_patch00m.en.bin — английский архив после подготовки Restoration;
decryptKey.bin и SomeKey.bin;
main.exe;
папка russian_merge со скриптами сборщика.
Откройте эту папку в Проводнике. Кликните по адресной строке, введите powershell и нажмите Enter.

В открывшемся окне PowerShell вставьте команду:


Нажмите Enter и дождитесь завершения. Если появится сообщение, что Python 3.10 не найден, проверьте установку командой py -3.10 --version.

После успешной сборки рядом появится patch00m.ru.bin. Это выходной файл — указывать его среди входных архивов не нужно. Если файл с таким именем уже существует, сборщик не станет его перезаписывать: переместите или удалите старый результат и запустите команду снова.

Перед заменой архива в игре сохраните резервную копию оригинального игрового patch00m.bin.
