Что представляет собой 
Это отдельная утилита для сборки русского patch00m.bin с изменениями Restoration. Она не собирает лаунчер и сама не меняет файлы установленной игры. На выходе она создаёт отдельный архив, который пользователь при необходимости устанавливает вручную.



Как данные проходят через программу
Входные архивы используются для сравнения изменений в три стороны:

Чистый английский архив ──┐
                          ├─ сравнить изменения Restoration
Английский после          ┘
Restoration                   │
                              ├─ перенести их в русский архив
Русский исходный архив ───────┘
                                      ↓
                             patch00m.ru.bin

Сборщик работает примерно так:

Открывает архивы FPD и читает их каталог с записями.
Сравнивает чистую английскую базу с английской версией после Restoration, чтобы найти изменённые и добавленные файлы.
Для сценариев .ks пытается объединить изменения построчно: сохраняет русские правки и накладывает непересекающиеся изменения Restoration. Если изменения затрагивают одни и те же строки, сборка останавливается с конфликтом.
Для EPK-таблиц использует main.exe и SomeKey.bin для расшифровки. В таблицах сообщений сохраняет уже существующие русские строки, а недостающие добавляет из Restoration. В таблицах метаданных изменения объединяются по ID и полям; при конфликте программа прекращает сборку.
Добавляет записи Restoration, которых не было в русском архиве, например новые сценарии и .tl-файлы.
Записывает результат в отдельный FPD-архив и проверяет его. Неизменённые русские данные должны сохраниться, а новые и объединённые записи — читаться обратно.
Для EPK-таблиц программа временно копирует main.exe и SomeKey.bin во временную папку и удаляет эту папку после работы.


Запуск и код
build_russian_patch_latest.bat — готовая команда для плоской раскладки: передаёт сборщику имена всех входных файлов и имя результата.
build_russian_patch.bat — запускает Python-скрипт и показывает сообщение об успехе или ошибке. Если использовать его без параметров, сборщик ожидает исходные файлы в стандартной структуре подпапок. Для текущей плоской раскладки лучше использовать build_russian_patch_latest.bat.
build_russian_patch.py — небольшая точка входа: передаёт управление основному модулю.
В russian_merge лежит логика сборки:

build_all.py — оркестратор: открывает три архива, находит изменения и добавления, вызывает алгоритмы слияния, записывает и проверяет итоговый архив.
fpd.py — чтение и запись FPD: каталог, смещения, сжатие, XOR-шифрование и перенос неизменённых данных.
merge_scene.py — трёхстороннее построчное слияние .ks и обнаружение конфликтов.
convert_scene.py — взаимодействие с EPK-утилитой, обработка таблиц сообщений и метаданных.
init.py — обозначает russian_merge как пакет Python.
Файлы в russian_merge\__pycache__ — автоматически созданный Python-кэш. Он не является исходным кодом и для запуска не обязателен.

Входные архивы
original_patch00m.bin — чистый английский архив до Restoration; база для сравнения.
restored_patch00m.en.bin — английский архив после подготовки Restoration; источник восстановленных изменений.
russian_patch00m.bin — исходный русский архив; он служит основой результата.
Важно, чтобы чистая и восстановленная английские версии соответствовали друг другу и нужной версии игры. Русский архив должен быть совместим с ними по формату.

Инструменты и ключи
decryptKey.bin — ключ для чтения и записи FPD.
SomeKey.bin — ключ, который использует EPK-инструмент; в этой копии его размер — 5120 байт.
main.exe — внешняя EPK-утилита: используется для расшифровки и обратного шифрования таблиц.
Эти файлы нужны локально. Не следует публиковать ключи или архивы игры.

Результат
patch00m.ru.bin — создаваемый результат, а не входной файл. Не используйте его как русский исходник при следующей сборке: входом должен оставаться russian_patch00m.bin.
